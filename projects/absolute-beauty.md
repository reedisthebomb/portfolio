# Absolute Beauty — Salon Operations Dashboard

**One line:** Private business operations dashboard for a salon — appointments, clients, inventory, and services with durable server-side storage.

## Overview

A full operations dashboard built for a real, operating small business (a salon), replacing manual/paper tracking with a persistent, server-backed system for daily scheduling and business management.

## Engineering highlights

- Server-persisted data model: appointments, business settings, services, clients, and inventory all durable across sessions (no sample/demo data — every empty state is a genuinely honest empty state).
- Working day-of navigation across Today, Calendar, Services, Inventory, Clients, and Business views.
- Responsive editorial-style UI designed for both desktop admin use and phone use on the salon floor.
- Payment-processor integration (Square) scoped and planned, with the current UI state honestly reflecting "not yet connected" rather than faking readiness.

## Stack

React 19, TypeScript, [vinext](https://www.npmjs.com/package/vinext), server-side persistence.

## Status

Live, in use by the business.
