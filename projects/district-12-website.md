# A.A. District 12 Website

**One line:** Public information website for a regional service district, built with a modern static-site toolchain.

## Overview

A public-facing informational website for A.A. District 12 (South Arkansas), giving the district a clean, maintainable web presence separate from any operational/registration system.

## Engineering highlights

- Modern static-site architecture (Astro) with separate local-dev and production-preview ports for safe iteration before publishing.
- Built as public information content only — kept intentionally separate from the private convention registration system that handles real transactions and personal data.

## Stack

Astro, Node.js/npm tooling.
