# Certifications

Google Career Certificates earned/in progress through Coursera. Each certificate has its own folder with completion status, credential ID, a public verification link, and the covered coursework.

Coursera and Credly issue a verification link for every completed certificate, and in 2025 LinkedIn added direct integration with both — so a completed certificate shows a "Verified" badge automatically once claimed there too. Use the **Verify link** field in each folder for that same public verification URL.

## Adding a new certificate

Copy the [`_template`](_template/README.md) folder, rename it to the certificate's slug (e.g. `google-data-analytics`), fill in the front-matter fields, and add a row to the table above. Full steps are in the main [SETUP.md](../SETUP.md).
